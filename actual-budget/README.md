# Actual Budget

[Actual Budget](https://actualbudget.org/) is a local-first personal finance
app with envelope budgeting. Your budget is stored on your own server and
synced between your devices.

This add-on runs the official Actual Budget sync server and web app inside
Home Assistant.

## Features

- Persistent storage of budget files in the add-on data
- Optional HTTPS using your Home Assistant certificates
- Web interface on port 5006

See the **Documentation** tab for setup instructions.
