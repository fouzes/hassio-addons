# Firefly III

[Firefly III](https://www.firefly-iii.org/) is a self-hosted manager for your
personal finances. It helps you track expenses, income and budgets and gives
you reports about where your money goes.

This add-on runs the official Firefly III image inside Home Assistant.

## Features

- Persistent storage and an auto-generated application key
- Built-in SQLite database, or an external MySQL/MariaDB server
- Configurable time zone, language and trusted proxies

See the **Documentation** tab for setup instructions.
